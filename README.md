# 电商视觉 AI 工作台（公开模板）

这是一套给电商视觉设计师使用的本地工作台模板。它把商品主图、详情页、视频方案、提示词和复盘资料分开管理，方便个人或小团队直接复制后开始项目。

## 适合谁

- 做淘宝、天猫、京东、抖音、小红书、亚马逊等电商视觉内容的设计师。
- 希望用 AI 辅助整理卖点、写版式方案、生成提示词和复盘经验的人。
- 想把真实项目资料留在本机，不误传到公开仓库的人。

## 先看这几个文件

- `00-开始使用/开始使用.md`：从建项目到交付的使用顺序。
- `00-开始使用/文件夹使用规则.md`：资料、方案、素材分别放在哪里。
- `00-开始使用/平台页面设计尺寸速查.md`：做图前确认画布与上传尺寸。
- `00-开始使用/AI操作红线.md`：客户资料、版权和账号安全的基本边界。
- `00-开始使用/常用技能清单.md`：适合电商设计工作的 AI 能力导航。
- `00-开始使用/5分钟启动.md`：第一次下载后，只做 3 步即可开始。
- `01-视觉方案/00-示例项目-天猫-封闭式猫砂盆-详情页/`：虚构项目，展示资料、策划和提示词如何组织。
- `00-开始使用/发布前检查清单.md`：每次公开发布前的快速检查。

## 文件夹结构

```text
00-开始使用/       使用说明、尺寸表、通用规则
01-视觉方案/       商品主图、详情页、活动页等真实项目（默认不上传）
02-视频方案/       视频需求表与视频方案模板
03-AI提示词库/     可复用的卖点、主图、详情页和视频提示词
04-复盘案例/       可复用复盘模板；真实案例默认不上传
```

一个视觉项目建议使用下面的结构：

```text
01-视觉方案/
└─ 项目编号-平台-商品名-工作类型/
   ├─ 01-商品资料
   ├─ 02-视觉参考
   ├─ 03-策划方案
   └─ 04-素材交付
```

## 使用方式

1. 复制或 Fork 本仓库到自己的电脑。
2. 先阅读 `00-开始使用/开始使用.md`，再按项目结构建立第一个项目。
3. 把长期通用的提示词放进 `03-AI提示词库`；把客户资料、产品图和项目成品留在项目文件夹内。
4. 使用前按自己的平台、团队和品牌规范修改 `AGENTS.md`。

## 公开与隐私边界

本模板故意不包含真实客户项目、私人工作流、账号信息、自动化脚本、个人 skills、下载参考图和本机配置。`.gitignore` 已默认阻止这些内容被上传。

公开前仍请自行检查：客户名称、产品图片、价格、内部文案、联系方式、账号凭据、第三方参考图授权。
