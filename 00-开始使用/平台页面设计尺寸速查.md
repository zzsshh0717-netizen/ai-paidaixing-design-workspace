# 平台页面设计尺寸速查

用途：集中存放各个平台的页面、主图、详情页、A+、社媒图等设计尺寸，方便不同 AI 工作流随时引用。

整理日期：2026-06-08

使用方式：做图前先看对应平台尺寸，确认画布比例、模块规格和导出要求。不要把平台尺寸写死到某一个商品项目或某一个工作流文件里。

## 1. 使用原则

- 平台尺寸资料统一放在本文件，工作流只引用本文件，不重复写一遍。
- 商品项目文件夹里只放该项目的策划、大纲、提示词、审核记录和素材。
- 本文件只做尺寸参考，不决定每一屏的具体内容、卖点顺序或画面方案。
- 高级 A+ 每屏放什么，优先看产品项目的实际情况、页面策划和分屏大纲。
- 平台规则可能会变，正式上传前还要看一次后台当前提示。
- 如果后台提示尺寸和本文件不一致，以后台当前提示为准。
- 如果是 AI 出图，先按最终页面比例出图，再按平台尺寸二次排版和裁切。

### 2.4 高级 A+ 建稿与导出规格

| 项目 | 建议 |
| --- | --- |
| 主工作画布 | 先按 `1464 x 600 px` 做桌面端主图。 |
| 移动端画布 | 对需要移动端图的模块，单独做 `600 x 450 px`，不要直接等比缩小。 |
| 模块数量 | 高级 A+ 每个项目最多 7 个模块；具体用几个模块、每个模块放什么，以项目实际策划为准。 |
| 安全区域 | 重要内容建议避开最边缘区域，防止不同设备预览时被裁切或压缩。 |
| 文字大小 | 本文件不规定具体字号；只提醒移动端图需要单独检查可读性。 |
| 导出格式 | JPG、PNG 或 BMP，使用 RGB 色彩；不支持动态 GIF。 |
| 文件大小 | 单张图片不超过 2 MB。 |
| 图片清晰度 | 至少 72 DPI。网页最终清晰度主要由像素尺寸决定，不要只提高 DPI。 |
| Full Video 视频 | MP4；最低分辨率 960 x 540；单条不超过 200 MB、180 秒；预览图 1464 x 600 px。 |
| 预览检查 | 上传后必须看桌面端和手机端预览，重点检查是否裁切、变形、压缩发糊、热点位置错位。 |

### 2.5 亚马逊 A+ 尺寸上传前检查

- 所选模块的桌面端图片尺寸是否正确。
- 需要移动端图的模块，是否单独准备了移动端图片。
- 1464 x 600 的桌面图是否没有被误做成竖版详情页。
- 600 x 450 的移动端图是否没有直接粗暴裁掉关键信息。
- 图片格式是否为 JPG、PNG 或 BMP。
- 单张图片是否不超过 2 MB。
- 视频模块的封面图、视频格式、视频大小和视频时长是否符合后台要求。
- 上传后桌面端和手机端预览是否没有裁切、变形、发糊或热点错位。
