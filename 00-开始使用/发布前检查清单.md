# 发布前检查清单

每次推送到公开 GitHub 前，按下面检查一遍。两分钟能避免大部分低级事故。

## 隐私与资料

- [ ] 没有客户名称、联系人、电话、邮箱、地址、内部价格、合同或未公开产品资料。
- [ ] 没有账号、密码、验证码、Cookie、API Key、Token 或本机电脑路径。
- [ ] `01-视觉方案`、`04-复盘案例`、`05-AI工作流`、`99-临时资料`、私密资料目录和 `.agents` 没有新增真实子文件夹。

## 图片与版权

- [ ] 所有公开图片、字体和图标都确认拥有版权、授权，或已替换为原创/占位素材。
- [ ] 没有下载的竞品图、品牌图、花瓣参考图或客户素材。
- [ ] AI 生成图已检查产品结构、包装文字、品牌标识与人物肖像。

## 模板可用性

- [ ] README 的链接可打开，5 分钟启动页步骤能走通。
- [ ] 示例项目明确标注“虚构演示”，没有真实品牌和参数。
- [ ] 新增模板已写入 `CHANGELOG.md`。
- [ ] `.gitignore` 仍能拦住真实项目、私密资料和本机配置。

## GitHub 发布

- [ ] README 写清楚模板用途、使用方法和适合人群。
- [ ] 已添加 `LICENSE.md`，并确认它禁止未经许可的转载、镜像、打包分享、售卖和公开发布改版。
- [ ] 仓库可见性、仓库名称和描述已复查。
