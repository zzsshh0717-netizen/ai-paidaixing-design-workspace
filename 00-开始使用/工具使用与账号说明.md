# 工具使用与账号说明

这个文件记录哪些工具适合做什么，以及使用时要注意什么。

## 日常工具分工

### 做图片生成

优先使用：
- `baoyu-imagine`

适合：
- 主图背景
- 详情页场景图
- 小红书封面图
- 氛围素材

注意：
- 生成图要二次检查。
- 商品结构、颜色、包装文字不能被改错。
- 不建议把 AI 生成图不检查就直接商用。

### 做小红书图文卡片

优先使用：
- `baoyu-image-cards`

适合：
- 小红书多页图文
- 种草卡片
- 卖点拆解
- 知识型卡片

注意：
- 首图要有点击理由。
- 每页只讲一个重点。
- 不要太像硬广。

### 做封面图

优先使用：
- `baoyu-cover-image`

适合：
- 小红书首图
- 文章封面
- 活动主题图

### 做信息图

优先使用：
- `baoyu-infographic`

适合：
- 参数对比
- 功能说明
- 使用步骤
- 卖点证据链

### 做视频方案和短片分镜

优先使用：
- `tvc`
- `ffmpeg`

适合：
- 主图视频方案
- 详情页首屏短片
- 产品组装视频拆解
- 竖版种草短片
- 视频关键帧和视频生成提示词

注意：
- 先看产品图和实拍/组装视频，再写分镜。
- 产品结构、安装方式、使用方式不能编错。
- 视频里的文字、Logo、价格建议后期手动添加。
- `ffmpeg` 用来抽帧、裁剪、压缩和转格式，不负责生成画面。

### 读网页和保存参考资料

优先使用：
- `baoyu-url-to-markdown`
- `playwright`
- `defuddle`

适合：
- 保存网页内容
- 读取小红书、博客、参考文章
- 学习竞品内容

注意：
- 小红书经常需要登录。
- 如果页面要求扫码登录，需要你在浏览器里手动登录。
- 浏览器产生的临时截图默认不当作正式素材。

### 写入正式 Obsidian 知识库

正式知识库位置由每位使用者自行设置。

注意：
- 当前工作台只是项目和模板目录，不是正式 Obsidian 知识库。
- 当你要求“写入 Obsidian”或“整理到知识库”时，应写入你自己的正式知识库位置。

## 账号和登录注意

- 小红书、图片生成工具、网页读取工具可能需要登录。
- 登录时如果出现二维码或验证码，需要你自己操作。
- AI 不应该保存或公开你的账号、手机号、验证码、密码。
- 不要把账号密码写进项目文件。

## API 和密钥注意

如果以后用到 API Key、密钥、Token：

- 不要放进普通文档。
- 不要上传到 GitHub。
- 不要写进提示词库。
- 如果必须保存，先问清楚保存位置。

你现在如果只是做视觉方案和图片生成，通常不需要手动管理这些技术配置。

## 推荐使用顺序

1. 先用需求表讲清楚任务。
2. 再用卖点提炼提示词整理卖点。
3. 再用主图、详情页、视频或小红书提示词生成方案。
4. 需要画面素材时，再调用图片生成。
5. 最后把好用的结果写进复盘案例。
